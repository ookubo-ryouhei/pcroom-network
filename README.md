# PC教室の配線

情報Ⅰ「ネットワーク」の授業で使うWebアプリです。生徒はネットワーク工事の担当者として、ある学校のPC教室（架空の教室）の配線に取り組みます。

- `index.html`：一覧
- `sekou.html`：第1時　施工と検査（図面どおりの施工、他の業者の施工の検査、不具合の調査）
- `kaishuu.html`：第2時　改修の設計（故障の影響の調査、机の移動と床の工事に合わせた配線の設計、作業の順番）

机は前から横列に並べています（第1時：3・2・3・2、第2時：3・3・3・1）。

外部のライブラリを使わず、`images` フォルダの画像だけを読み込みます。GitHub Pagesでそのまま公開できます。
